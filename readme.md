# 🤖 Agentic AI Career Assistant

An AI-powered career assistant that helps users plan their career, create study plans, manage learning tasks, track progress, and maintain user memory.

## ✨ Features

- 🎯 Career goal detection and profile management
- 🧠 Semantic understanding of user requests
- 📚 Personalized study plan generation
- 📋 Learning task management
- ✅ Task completion tracking
- 📊 Progress calculation
- 💡 Career roadmap and advice
- 🧠 Persistent user memory
- 🔧 AI tool calling
- 🤖 Agentic decision-making
- 💬 Natural language interaction
- 🌐 Streamlit web interface

## 🛠️ Technologies Used

- 🐍 Python
- 🤖 Google Gemini API
- 🌐 Streamlit
- 🔧 Google GenAI SDK
- 💾 JSON-based memory
- 🔐 Python-dotenv
